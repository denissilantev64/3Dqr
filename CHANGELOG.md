# Changelog

Все значимые изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-06-22

### Добавлено
- Первоначальный релиз 3D QR Code Generator
- Генерация QR-кодов с настраиваемыми параметрами
- Создание 3D мешей с выпуклой структурой
- Эффект внутреннего свечения
- Поддержка множественных форматов экспорта (PNG, HTML, OBJ, PLY, STL)
- Интерактивная 3D визуализация с Plotly
- Высококачественный рендеринг с Matplotlib
- Гибкая система конфигурации через JSON
- Интерфейс командной строки с множественными опциями
- Система сглаживания краёв
- Настраиваемое освещение и материалы
- Создание анимации вращения
- Полная документация и примеры
- Автоматизированные тесты
- Makefile для удобства разработки

### Технические особенности
- Поддержка Python 3.8+
- Модульная архитектура
- Валидация конфигурации
- Обработка ошибок
- Подробное логирование
- Оптимизированная производительность

### Форматы экспорта
- **PNG** - Высококачественные растровые изображения
- **HTML** - Интерактивные 3D модели
- **OBJ** - 3D модели для Blender/Maya
- **PLY** - 3D модели с цветами
- **STL** - Модели для 3D печати

### Примеры конфигураций
- Настройки по умолчанию
- Синее свечение
- Неоновый стиль Matrix
