# Руководство по участию в проекте

Спасибо за интерес к проекту 3D QR Code Generator! Мы приветствуем вклад от сообщества.

## Как внести вклад

### Сообщение об ошибках

1. Проверьте, что ошибка не была уже сообщена в [Issues](https://github.com/denissilantev64/3Dqr/issues)
2. Создайте новый Issue с подробным описанием:
   - Версия Python и операционная система
   - Шаги для воспроизведения ошибки
   - Ожидаемое и фактическое поведение
   - Логи ошибок (если есть)

### Предложение новых функций

1. Создайте Issue с описанием предлагаемой функции
2. Объясните, зачем эта функция нужна
3. Предложите возможную реализацию

### Отправка кода

1. Форкните репозиторий
2. Создайте ветку для вашей функции (`git checkout -b feature/amazing-feature`)
3. Следуйте стандартам кодирования проекта
4. Добавьте тесты для новой функциональности
5. Убедитесь, что все тесты проходят
6. Зафиксируйте изменения (`git commit -m 'Add amazing feature'`)
7. Отправьте в ветку (`git push origin feature/amazing-feature`)
8. Откройте Pull Request

## Стандарты кодирования

### Python код

- Следуйте PEP 8
- Используйте type hints где возможно
- Добавляйте docstrings для всех публичных функций и классов
- Максимальная длина строки: 88 символов (Black formatter)

### Форматирование

Используйте Black для форматирования:
```bash
make format
```

### Линтинг

Проверьте код линтером:
```bash
make lint
```

### Тестирование

Запустите тесты перед отправкой:
```bash
make test
```

## Структура коммитов

Используйте понятные сообщения коммитов:

- `feat: добавить новую функцию`
- `fix: исправить ошибку`
- `docs: обновить документацию`
- `style: изменения форматирования`
- `refactor: рефакторинг кода`
- `test: добавить или изменить тесты`
- `chore: обновление зависимостей или конфигурации`

## Настройка окружения разработки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/denissilantev64/3Dqr.git
cd 3Dqr
```

2. Создайте виртуальное окружение:
```bash
make venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```

3. Установите зависимости для разработки:
```bash
make install-dev
```

4. Запустите тесты:
```bash
make test
```
